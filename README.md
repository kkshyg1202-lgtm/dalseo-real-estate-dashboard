# 달서구 부동산 브리핑 대시보드

에일린의뜰 대표공인중개사사무소의 고객 브리핑용 Cloudflare Worker 사이트입니다.

## 실행

```powershell
node scripts\dev-server.mjs
```

기본 미리보기 주소는 `http://127.0.0.1:4173`입니다.

## 서버 환경변수

- `PUBLIC_DATA_API_KEY`: 공공데이터포털 일반 인증키
- `REB_API_KEY`: 한국부동산원 R-ONE 인증키

인증키는 브라우저 번들 또는 저장소 파일에 넣지 않습니다. 배포 플랫폼의 암호화된 서버 환경변수로 설정하세요.

## 데이터 연결

- `/api/trades`: 국토교통부 아파트 매매·전월세 실거래 조회 프록시
- `/api/market-index`: 한국부동산원 지수 연결 지점
- 달서구 법정동 코드: `27290`

API가 설정되지 않은 로컬 미리보기에서는 브리핑용 샘플 데이터가 표시됩니다.
